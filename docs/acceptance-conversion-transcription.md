# 四项工具本地验收记录

日期：2026-09-15。环境：本机 macOS、Next.js、独立 worker、PostgreSQL、Redis、MinIO、原生 FFmpeg、项目 Python 虚拟环境。

## 交付内容

- 视频、音频、图片格式转换：真实处理、批量最多 20 个文件、基础/高级参数、兼容预览、单文件与 ZIP 下载。
- 音视频转文字：阿里云百炼北京地域 `fun-asr`，原生异步识别、分段时间戳及说话人、编辑保存、五种导出。
- 四个工具在中英首页开放；转写未配置密钥时禁止提交并提示配置。
- 新迁移 `0004_conversion_transcription.sql`、`0005_transcription_provider_tasks.sql` 已在本地应用。密钥只在被忽略的本地环境文件中保存。

## 转换验证

`pnpm test:converters`：105 个成功转换、5 个明确拒绝，通过实际解码检查，报告为 `.data/conversion-checks/report.json`。

覆盖视频四种容器互转及 H.265，音频六种格式互转，图片各输入格式到四种输出；包含 HEIC、AVIF、透明和动画。边界样本覆盖旋转、非方形像素、可变帧率、奇数尺寸、竖屏、不放大、无音轨、多音轨、音轨偏移、低采样率、24 位无损输出及 HDR 拒绝。

后缀、MIME、实际编码与输出参数分别校验。音频预览和视频兼容预览不替换用户选择的下载格式；失败不会返回原文件冒充转换结果。

**识别质量边界：**两小时样本是重复语音压力样本，不是自然会议准确率测评。跨分段共返回 30 个独立说话人标识，其中 27 个标为待核对；有些分段会把同一人再分成不同标签。切分边界也观察到短词重复，例如相邻片段出现重复的“大家好”。保守的重叠去重不能代替人工校对，编辑器允许修改文字、时间及说话人。不能据此承诺任意录音零识别错误。

## 编辑与恢复

浏览器覆盖中英双语、桌面和手机：

- 上传、刷新、批量结果、预览、单文件和 ZIP 下载。
- 文字修改、拆分/合并、说话人改名、保存状态、五种导出。
- 100 条分页后继续加载；把片段时间移到后页，再加载不会漏项或重复。
- 跨标签页版本冲突不会覆盖已保存修改；导出显示版本，历史文件不冒充新结果。

`pnpm test:transcription` 使用固定识别响应，但运行真实 FFmpeg、存储、数据库与导出，共 7 组通过：

1. 两小时真实媒体分段，部分失败后保留已完成文字。
2. 手动重试只处理未完成分段，恢复源时间轴。
3. 归属、版本冲突、导出去重、重复队列投递及不可变版本快照。
4. 导出取消/重试及过期后的读取、保存、下载拒绝。
5. 重复识别投递不会干扰正在处理的请求；取消保留不确定状态。
6. 强制终止测试进程后，没有云端任务 ID 的请求不会自动重发。
7. 已保存云端任务 ID 后强制终止测试进程，恢复使用原任务及原服务配置。

测试时已停止普通 worker，只终止测试自身创建的进程组，结束后恢复普通 worker。

## 本地运行边界

- 图片每个 50 MiB，音视频每个 1 GiB，单个转换输出最多 4 GiB；转写最长 2 小时。
- 本地原件、预览、转写文档、识别分段、导出及 ZIP 沿用 24 小时有效期，访问受归属和过期校验约束。
- 百炼临时上传的云端副本由服务商在 48 小时后清理。删除本地任务不会提前删除云端副本；取消本地任务后，云端已接收的识别可能继续完成。生产需要自有 OSS 与清理策略。
- 已保存云端任务 ID 时，查询恢复不重新提交；未拿到 ID 的不确定提交由用户明确重试，可能再次计费。
- Supabase 登录、真实 R2、支付扣费、云端部署和生产资源隔离仍属于后续阶段。本轮没有 push、PR、远程 CI 或部署。

官方依据：[百炼 Fun-ASR 录音接口](https://help.aliyun.com/zh/model-studio/fun-asr-recorded-speech-recognition-http-api)、[百炼临时文件上传](https://help.aliyun.com/zh/model-studio/get-temporary-file-url/)。

静音真实调用补充：百炼返回 `ASR_RESPONSE_HAVE_NO_WORDS` 时，应用现在将其作为空识别结果完成；同类 `SUCCESS_WITH_NO_VALID_FRAGMENT` 也按空结果处理。文件下载、格式或其他服务失败仍保持失败状态。已添加单元回归，并通过新的纯静音真实调用验收。[阿里云错误码说明](https://help.aliyun.com/zh/model-studio/error-code)。
