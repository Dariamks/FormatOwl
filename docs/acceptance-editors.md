# 四个媒体编辑工具：本地验收

验收日期：2026-09-15。新增视频剪切、视频画面裁剪、音频剪辑、视频转 MP3；首页 8 个工具可用，其余 7 个工具仍为即将推出。运行环境为本地匿名会话、PostgreSQL、Redis、私有 MinIO 与原生 FFmpeg。

## 功能

| 工具         | 已实现                                                                                                                         |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 视频剪切     | MP4/MOV/MKV/WebM；毫秒时间输入、可拖动与键盘调整的时间轴、多选区保留/移除；按原顺序重编码合成 MP4/MKV/MOV                      |
| 视频画面裁剪 | 自由/原比例/16:9/9:16/1:1/4:3/3:4/5:4；鼠标和触屏拖动/缩放、像素输入、实时裁剪预览；方向与像素比例校正、偶数像素坐标           |
| 音频剪辑     | MP3/WAV/AAC/M4A/M4R/FLAC/OGG 和视频音轨；多源、波形选段、复制/删除/排序、每段淡入淡出；MP3/WAV/M4A/M4R 导出及完整 M4A 成品试听 |
| 视频转 MP3   | 默认音轨识别、切换音轨、全长或指定区间、128/192/320 kbps、波形试听与 MP3 下载                                                  |

- 统一上传、准备、编辑、导出、结果预览和下载。视频使用 H.264/AAC 代理，音频使用 M4A 及 worker 预计算波形；最终结果始终从原件生成。
- 自动保存本浏览器草稿，准备过程中刷新仍能恢复；上传未完成时重新选择原文件续传。结果页可返回编辑并创建新结果，历史结果保留。
- 多源任务记录完整来源、片段与用途；创建/重试校验所有源的归属、状态和到期时间。删除试听或导出结果后，仍可编辑的源保留到原有效期。
- 修改参数会立即移除旧成品试听播放器；音轨切换和恢复草稿使用对应音轨的代理。

### 输出内容与特殊样本

- 剪切验证时长；输入选区乱序后按原视频时间顺序输出，重叠区间合并；移除模式计算补集。
- 彩色分区视频裁剪后实际解码取像素，验证导出内容为选中的黄色区域。
- 验证 90° 旋转、非方形像素、VFR、无音轨、多音轨与音画起点偏移；偏移样本检查起始静音和后续声音能量。
- 22.05 kHz WAV 与视频音轨混合拼接后为 44.1 kHz 双声道。WAV 输出通过 RMS 验证淡入/淡出，通过 660/880 Hz 频率能量验证片段顺序和音轨选择。
- HDR 画面编辑明确拒绝，HDR 音轨提取成功；损坏源和不存在音轨返回错误。M4R 超长拒绝且不自动截断。
- 真实编码回归主动注入 FFmpeg 启动时可能出现的 `out_time_us=N/A`，验证该进度被忽略，避免写入无效数据库整数。
- 浏览器检查真实媒体加载、播放/下载、数字输入、时间轴键盘操作、波形拖动、裁剪鼠标/触屏操作、移动端溢出与草稿刷新。音轨试听通过实际解码代理并比较 440/880 Hz 频率能量验证。

## 默认边界

每次最多 20 个源文件、50 个片段、总输入 1 GiB、输出 24 小时；M4R 最长 30 秒。视频工具每次一个源文件，画面编辑支持 SDR。默认 24 小时有效期、每日 20 次上传、20 个活跃任务；准备和成品试听也计入活跃任务。

本次为本地真实处理交付，未覆盖 1 GiB/24 小时满载压测、Safari/Firefox 或完整真实移动设备矩阵。Supabase 登录、云端 R2、计费、云盘、多轨混音、跨视频拼接和部署不属于本轮验收。没有 push、PR、远程 CI、Tag、Release 或部署。

## 视频编辑器样式与格式更新（2026-09-15）

- 剪切画面移除浏览器原生控制条，画面下方提供静音、播放/暂停和时间；缩略图上的左右手柄支持鼠标、触屏和键盘（1 ms，Shift 为 100 ms），独立播放游标同步当前位置。时间输入支持 `HH:MM:SS.mmm`，也接受秒数。
- 保留/移除使用分段按钮，分别解释所选范围和剩余片段的处理。继续支持多个选区和原顺序合并。
- 裁剪使用八个比例按钮（包含 5:4），宽×高精确尺寸、可展开的 X/Y 与重置；播放条增加当前/总时间、进度、静音和音量。八个裁剪控制点位于四角及边缘中点。
- 两个工具支持 MP4/MKV/MOV。历史参数不含 format 时保持 MP4。选择格式参与已有任务幂等校验，保存在编辑草稿；修改裁剪比例、尺寸或重置仍保留格式。
- MKV/MOV 使用相应的真实封装，下载文件扩展名与 MIME 一致。worker 额外将结果无损重新封装成 MP4 用于浏览器预览；预览与下载资源分别签名，继续遵循结果清理逻辑。
- 封装参数依据 [FFmpeg 官方格式文档](https://ffmpeg.org/ffmpeg-formats.html#MOV_002fMPEG_002d4_002fISMV)；MOV 为 QuickTime，MP4/MOV 使用 faststart。
- 裁剪效果在暂停时只按编辑、跳转或媒体加载事件更新，播放时逐帧更新，避免静止画面持续重绘。

新增验证结果见根目录 `design-qa.md`。本轮不涉及上传/任务状态机或数据库迁移。
