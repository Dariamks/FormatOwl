# FormatOwl 国际化

网站支持 25 个稳定 URL 标识：`en ru zh zh-Hant tr id hi ja es fr ar uk ko pt de it ms ur pl vi nl th ro cs el`。`/zh` 是简体中文，HTML / hreflang 为 `zh-Hans`；`/zh-Hant` 是繁体中文。根路径仍永久跳转 `/en`，不按浏览器语言重定向。

## 维护入口

- `apps/web/src/i18n/registry.ts` 是语言代码、原生名称、HTML 标签、方向与 Open Graph locale 的唯一来源。路由、菜单、邮件、回跳和 SEO 从此派生。
- `apps/web/messages/en/*.json` 定义消息键与参数。每个语言目录具有相同的 26 个命名空间。`message-types.d.ts` 是由英文生成的键与参数契约，ICU 数量参数为 `number`。
- `pnpm check:i18n` 检查缺键、多键、空值、ICU 语法、参数、富文本标签，以及源代码中的静态翻译键。原有媒体参数、错误码和模型语言列表不变。
- `pnpm i18n:manifest` 生成显式服务端导入表、消息版本和类型契约。`pnpm build` 先校验并生成这些文件，随后执行生产构建。

新增语言：注册元数据，补齐该语言全部 JSON，校订译文，运行校验、构建和对应浏览器回归。翻译与代码一起发布，不需要数据库迁移、翻译服务或新框架。

## 加载边界

根 Provider 仅接收 `nav/common/errors`。首页和工具页面由服务端 `Messages` 边界传入当前语言的交互词典。创建表单和任务编辑器分别使用 `entryNamespaces` 与 `toolNamespaces`；任务详情读取任务类型后并行加载编辑器代码和词典。登录弹窗首次打开才请求 `login`，再次打开复用缓存。

指南、工具说明、SEO 长文和邮件通过服务端 `getSiteTranslations` 读取。`imports.ts` 与加载器标记 `server-only`；客户端仅引用命名空间的类型。HTTP 词典接口拒绝 `content/guide/homeServer/tool_information/page/email`，不把长文放进客户端 Provider。指南等服务端内容会正常出现在 HTML 中，便于搜索引擎和用户阅读。

服务端与客户端均按“语言＋命名空间”复用成功结果和进行中的请求，失败会移除缓存。HTTP URL 带词典内容版本并使用 immutable 缓存；部署后旧版本请求返回 409，重试提示会重新加载页面。缓存不包含会话、任务或文档数据。语言切换完整导航，不预取其他语言。

## 切换与方向

上传和关键保存期间禁用切换；未提交文件或未保存修改通过共享 guard 确认放弃，取消保留当前状态。URL 路径、查询和锚点保留，已有任务继续使用原 ID。网页语言独立于文档、转写和翻译目标语言；新增语言保留原有非中文界面的任务默认值。

阿拉伯语、乌尔都语设置 RTL。Select 传入组件方向，布局使用逻辑间距。时间轴、波形、画布坐标为 LTR；文档与转写正文按内容方向展示，混合文件名隔离。价格币种和计费规则不变。

## 译文质量范围

英文、简体中文沿用并迁移已有文案。繁体中文独立保存，校订帳戶、信箱、浮水印、裁切等术语。新增 22 种语言有独立词典，没有整页英文回退；品牌、格式和技术标识保留原文。

新增语言长文采用本地离线 M2M100 辅助生成，工具名称、导航、登录、页码、复数和关键编辑按钮另行校订。词典完整性、占位符和 ICU 校验不代表完整母语审校；这些长文仍应由对应语言的审校者确认表达与术语。离线模型和临时生成文件仅位于被忽略的 `.data/i18n`，不作为运行时依赖，不随网站发布。模型来源：[Meta M2M100](https://huggingface.co/facebook/m2m100_418M)。

## 验证命令

```sh
pnpm check:i18n
pnpm typecheck
pnpm test
pnpm build
# 本地网页、worker 与基础设施运行时；无付费模型调用
pnpm test:integration
pnpm exec playwright test tests/e2e/i18n.spec.ts tests/e2e/i18n-auth.spec.ts
pnpm exec tsx scripts/measure-i18n.ts http://127.0.0.1:3001
```

邮件测试强制使用本地 mailbox，不验证 Google OAuth 或 Resend 真实送达。历史阅读浏览器用例依赖 `.data/translation-live` 的有效文件；过期样本不能作为当前阅读交互已通过的证据。当前国际化回归覆盖创建表单、媒体编辑器、任务恢复和语言加载，不生成新的付费阅读样本。

性能脚本检查生产 HTML 中的 Provider 消息边界，并记录初始脚本请求数量、gzip JS 和消息载荷。它测量初始导航资源，不等同于上传后完整编辑器的全部资源或交互延迟。

翻译与转写的全屏工作区也提供共享语言菜单。`tests/e2e/i18n-editor.spec.ts` 使用固定文档、阅读与预览响应验证正文方向、实际编辑器保存请求期间的切换禁用，不会调用模型。
