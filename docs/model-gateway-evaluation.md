## 怎样测试

- 读取网关 `/models`，得到 32 个模型 ID，包含大小写不同的名称；没有把“出现在列表里”等同于接口可用。
- 八个主要文本候选分别做六类短翻译、两轮重复；额外测试 `GLM-5.1` 大写 ID。与当前原生模型使用相同输入比较。
- 两个 Qwen 候选继续做 11 种目标语言，以及研究结论、格式和术语样本，各两轮。
- 入选 `qwen3.6-plus` 再做 3,563 字中文长文本，按实际生产方法切为两段，保留 36 个内容标识；英、阿拉伯、德语各两轮。
- AI 阅读覆盖结构化摘要、导图、事实问答、无答案问题、输出语言和恶意指令样本。校验 JSON、节点树、内容 ID 和引用原文，并阅读输出核对事实。
- 最有希望的阅读候选 GLM 继续测试已有 PDF 的 72 个文字块和七块合成 DOCX，各做摘要、导图及问答。**这不是把原 40 页 PDF 全部重新翻译并验收。**
- 图片修复比较菜单、渐变、网格和纹理；后三类每模型两轮。使用生产裁剪、局部合成方法，与已知无文字背景和原模型比较。
- OCR 补测两栏中英文字、小字和旋转文字，两轮；比较识别结果以及实际文字框覆盖范围。

重复测试是分别提交请求；网关是否在内部缓存、转发或映射模型无法独立验证。结果反映本次账号、接口和样本，不代表模型在所有场景下的排名。

| `qwen3.5-flash`        | 数字/标识检查通过，响应较快；阿拉伯语样本存在语法问题，阅读导图结构不稳定                                                    | 不作为默认；保留测试记录                                             |

| `deepseek-v4-pro-0428` | 两轮均省略上述指令式原句；阅读出现无效引用                                                                                   | 不替换                                                               |
| `deepseek-v4-flash`    | 同样出现整句遗漏；结构化阅读有返回模式定义、缺字段或超时                                                                     | 不替换                                                               |
| `kimi-k2.6`            | 短翻译可用；阅读有漏引用、语言偏离，并曾把两个方案相同的保留期限说成区别                                                     | 不替换默认翻译或阅读                                                 |
| `minimax-m2.7`         | 短翻译可用但本轮较慢；三个阅读请求在 150 秒后仍未取得完整结果，另一个偏离输出语言                                            | 不替换；不自动重发结果不确定的请求                                   |
| `glm-5.1` / `GLM-5.1`  | 短翻译可用。小写 ID 在接受完整 JSON 代码围栏后通过八个初筛阅读样本；实际文件复测六项中五项通过，PDF 导图引用校验失败         | **阅读保持原样**；大小写 ID 不推定一定映射相同后端                   |

本次翻译要完整保留原文：遇到文件内的“忽略之前指令”应翻译这句话，不能执行，也不能静默删去。仅检查返回非空和 HTTP 200 无法发现这种漏译。

`qwen3.6-plus` 的 44 个场景共包含 50 次文本请求（长文场景各两次），另有实际文件处理调用。短翻译样本的中位响应约 1.36 秒，原生 `qwen-mt-plus` 约 0.47 秒；这是本次小样本观察，不是服务速度承诺。此次选择满足质量与网关使用需求，**不宣称它在质量、速度和价格上全面超过原模型**。未取得网关账单，不推算费用。

原阅读模型本轮也出现部分输出语言偏离；保留它是因为尚未验证到整体更稳的替换方案，不代表原链路不存在改进空间。

## OCR 与图像模型

### OCR

| 模型               | 两种图片 × 两轮结果                                                                                            |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| `qwen3.6-plus`     | 三次坐标越界；返回中混用了边界坐标与宽高，且尺度与要求不一致                                                   |
| `qwen3.5-flash`    | 四次返回 `bbox_2d` 等不同格式，使用了归一化坐标；旋转方向/角度也与输入不一致，不能只改字段名即用于现有修复流程 |
| `kimi-k2.6`        | 文字读对，水平文字定位较好；旋转样本的框偏位，两轮覆盖文字像素约 30%，会留下原文字                             |
| 原生 `qwen3.5-ocr` | 四次均读对，文字框覆盖测试文字像素 100%                                                                        |

像素覆盖率仅用于本次合成样本的定位检查，不等于通用 OCR 准确率。本轮未采用猜测坐标格式、放大遮罩等方式掩盖定位错误。

## 工程与实际文件验收

- 增加按功能选择网关的配置；文本翻译与 AI 阅读分开，OCR/修复不受开关影响。
- 网关使用 `/chat/completions`；保留原生请求协议、原任务的模型/地址快照和原凭据。
- 凭据不跨线路发送，禁止重定向转发；请求限流按线路、凭据及模型隔离。
- 明确 429 继续遵守退避；请求结果不确定时不自动换模型重发。截断输出明确失败。
- 网关阅读适配器保留结构与引用校验，但默认仍为原生阅读。不会通过修补不存在的引用来让模型“通过”。
- 54 项单元测试通过；`pnpm typecheck`、`pnpm build` 通过。
- 三种翻译工具共六项浏览器测试通过，覆盖桌面/手机、修改保存、刷新、冲突、预览和下载。修正了预览测试过宽的弹窗选择器；最终使用独立测试产物目录。
- 合成 DOCX、字幕视频、菜单图片均通过实际处理和下载，导出 DOCX、MP4、PNG；浏览器另验证 ASS 下载。
- 图片链路的一次原生修复请求结果不确定，显式重试后完成；异常发生在原生修复服务，已如实记录。
- web 与普通 worker 已按正式 `.env` 重启；额外新建 TXT 任务核对自动检测、网关路由、翻译和文件下载。

本次没有改媒体解析、排版和导出算法，没有执行破坏性故障恢复测试，也没有 push、PR 或部署。

## 本地证据与复验

原始请求结果、人工核对用图和测试产物位于忽略的 `.data/model-evaluation/`：

- `translation-*.json`、`languages-*.json`、`long-results.json`：翻译对照。
- `reading-files.json`：实际 PDF/DOCX 阅读复测。
- `images/*-comparison.png`、`images/metrics.json`：修复效果与局部合成检查。
- `ocr/coordinate-comparison.png`、`ocr/metrics.json`：文字框定位比较。
- `browser-confirmed.log`、`unit-tests.log`、`typecheck.log`、`build.log`：工程检查。
- `active-config-result.json`、`final-download.txt`：普通服务重启后的正式配置验收。

早期阅读检查曾把明确拒绝攻击时引用攻击字符串、全角时间标点等判成失败；另有诊断程序用于查看去除代码围栏后的结构。因此不把早期原始 `pass` 计数直接当成模型准确率。最终决定结合生产校验、实际文件复测和人工阅读。

持续维护的 `scripts/evaluate-model-gateway.ts` 复用生产请求构造器，支持 `translation`、`languages`、`reading`；显式设置 `EVAL_MODELS`、`EVAL_ROUNDS` 和网关测试凭据后运行。执行会产生实际调用，默认两轮；返回结果存入忽略目录。一次性图片、OCR、长文和既有文件复测脚本也保留在该本地目录。

恢复原文本翻译：设置 `TRANSLATION_TEXT_PROVIDER=dashscope`、`TRANSLATION_MODEL=qwen-mt-plus` 后重启 web/worker。保留网关密钥，以便已保存为网关线路的步骤继续完成。已经完成的内容和导出文件不因切换配置重新生成。
