# 去水印：实现与本地验收

四个入口共用一个工作区：图片、PDF、Word（DOCX）、PPT（PPTX）。单文件最大 50 MiB，图片最大 100 百万像素，文档最多 100 页／张，沿用原文件的 24 小时有效期。视频、Excel、DOC/PPT、宏文件和动画不在本次范围内。

## 操作与保存

上传后由 worker 读取结构、生成预览；安全的独立对象显示为未勾选候选。图片 OCR 在打开当前图片时执行，也可以手动框选、画笔补选和擦除。未配置 OCR 时仍可手动编辑图片和删除独立对象。

图片 OCR 选区会在本地检查文字周围紧凑、近似纯色的底板，将圆角底板和细描边包含在选区内；纯文字保留紧凑边距。检测限制搜索范围，拒绝延伸到周围背景或吞入邻近文字。它不是通用 Logo 分割，渐变、复杂纹理底板仍可能需要手动补选；扫描 PDF 保留原有正文保护及保守文字框。

已识别图片可点击“重新识别水印”，复用相同原图及 OCR 路线的已完成识别结果，重新计算选区。更新保留现有勾选及手工选区，不重复添加候选；边界变更递增草稿版本，使旧预览失效，已经生成的导出快照保持不变。

工作区支持缩放、撤销／重做、自动保存、刷新恢复、当前页预览、原始／结果／滑动对比和导出。PDF 重复对象可在命中列表中选择页面；扫描图像选区可复制到指定页面的图像并分别预览。Word 页眉显示节与页眉类型；PPT 显示版式、母版与受影响的幻灯片。共享对象按整个对象处理。

保存使用递增 revision。预览和导出冻结版本与选区；编辑后旧结果失效，当前下载只对应保存版本。已取得的旧版本导出保持不变，但仍检查归属、删除状态及有效期。

## 处理边界

- **图片**：先验证选区边界是否为纯色，符合条件时本地填充；其余局部裁切交给现有图片网关。模型同时接收上下文图和二值蒙版，只把确认蒙版内的结果合成回原图。四周全透明的选区可直接清除。PNG 和无损 WebP 保持蒙版外像素与透明度；JPG 编码本身有损且不保留透明度。
- **PDF**：只删除可隔离的绘制对象，或克隆并替换指定图像引用。共享绘图状态里的常见水印文字可单独清空字形，保留后续文字需要的字体、间距及路径状态；用于裁剪的非独立文字不提供此操作。文字、链接、书签和表单继续保留；没有整页转图片的输出路径。复杂图像蒙版、无法准确定位的对象不开放局部修复。扫描图像必须经过 OCR 正文保护，识别不可用时该操作明确失败。只有短而明确的常见水印标签可进入修复；普通正文、旋转段落、含水印关键词的正文或不确定文字与选区相交时均阻止修复。
- **DOCX/PPTX**：直接修改源 ZIP/XML 中被选择的节点及图片关系；图片替换克隆媒体引用，保留尺寸、旋转和裁剪设置。Word 的 AlternateContent 整体删除，同一图片的兼容分支同步替换；不同像素或尺寸的兼容图片不开放局部修复。页眉页脚中独立的常见短水印标签可选择删除。PPT 将符合文字、数量和包含边界条件的组合底板与水印文字作为一个候选，普通内容组合仍分别处理。预览包含隐藏幻灯片，导出保留隐藏标记。LibreOffice 仅生成预览，不重建最终文件。预览布局可能与 Microsoft Office 有差异。外链媒体、宏、签名文件拒绝处理；普通超链接保留。
- 独立对象列表包含需要人工判断的形状及文本，正常品牌、页眉和模板元素不会自动删除。PDF 先按水印关键词、有效字号、实际透明度、旋转及显式水印标记筛选文字，普通正文与公式字符不计入候选上限；图片仍需人工确认。渲染探测最多处理 500 个 PDF 候选或 300 个 Office 对象／图片，超限返回单独的对象数量错误，不与页数错误混淆。
- AI 修复不能恢复被遮住的真实内容，复杂纹理及网格可能发生细节变化。边界颜色校正用于减轻渐变接缝，不保证所有背景无缝。

## 工程接入

新增 `0009_watermarks.sql`，保存文档草稿、处理快照、结果和独立 OCR／修复步骤。网页只提交短 JSON 请求；原文件、渲染、OCR、修复、导出与清理均由 worker 完成。文件继续通过私有对象存储直传与签名下载。

客户端只提交候选 ID 和规范化蒙版，不持有 XPath、PDF 指令位置、对象 key 或处理命令。服务端校验文件归属、选区范围、版本、格式及删除／修复冲突。

队列使用持久化发件箱补偿，默认单并发。缓存绑定源内容、实际蒙版、模型路线和处理版本。重试保留完成的步骤；未知请求结果进入 uncertain，不能自动重发付费请求。取消、过期及删除会停止后续处理并清理文件。

OCR 复用百炼配置；修复复用 `TRANSLATION_IMAGE_PROVIDER`、`TRANSLATION_IMAGE_MODEL` 与图片网关。两项能力分别检查，独立对象删除不依赖 AI。修改处理代码后需重启 worker。

`test:watermarks:detection` 在普通 worker 运行时执行，使用合成圆角底板和预置 OCR 结果，验证真实上传、底板选区、重新识别、版本、缓存、预览及导出，不调用云端模型。浏览器去水印回归包含对应的桌面／手机复验。

`test:watermarks:documents` 生成 6 份 DOCX/PPTX/PDF 文档，通过真实 API 和 worker 上传、处理、预览、导出，再用独立文档库读回并逐部件比较。涵盖 Word 兼容表示及页脚、PPT 图表/备注/组合底板/隐藏幻灯片/共享图片、PDF 字体状态/表单/扫描正文保护。OCR 使用固定回归数据，图片走已验证的本地纯色修复，不调用云端模型；不能用此测试替代真实 OCR 或复杂背景 AI 效果验收。文档浏览器测试需要先运行此命令。

`pnpm test:watermarks:live` 使用合成渐变水印图片和真实模型，可能产生费用。报告保存在忽略的 `.data/watermark-test/`。重复执行读取已保存的运行 ID，不自动重发未知请求。
